# Holmes Burger Website

A static landing page built for Holmes Burger, a local restaurant chain in Egypt with branches in Alexandria and Cairo. This project was created to practice basic front-end development, focusing on structured layouts and CSS

## Sections Included

The webpage is a single-page layout consisting of the following sections:

*   **Hero Banner:** A top banner featuring the slogan ("Legendary Burgers, Egyptian Soul") and a basic call-to-action button.
*   **Menu Grid:** A display section showcasing four specific items with their ingredients and prices in EGP:
    *   Cheesy Mushroom
    *   Bloody Hell
    *   Grand Pa
*   and there is a basic call-to-action     button that is connected to the full lenu in another page.
*   **About Section:** A brief text column explaining the origin and story of the restaurant starting in Alexandria.
*   **Footer Directory:** Lists the specific branch locations across Alexandria and Cairo, along with a link to the official Facebook page.

##  Tech Stack

*   **HTML5:** Used for the core structure of the page.
*   **CSS3:** Used for the layout, custom background colors, text alignment
